# 北京精恒光辉门窗有限公司官网

## 项目概述

这是一个专业的企业官网项目，包含前台展示网站和独立的后台管理系统。

## 文件结构

```
网站代码/
├── index.html              # 主网站页面
├── styles.css              # 主网站样式
├── script.js               # 主网站JavaScript
├── admin-login.html        # 后台管理登录页面
├── admin.html              # 后台管理主页面
├── admin-styles.css        # 后台管理系统样式
├── admin-login.js          # 后台管理登录JavaScript
├── admin.js                # 后台管理主页面JavaScript
└── README.md               # 项目说明文档
```

## 技术特点

- **前端技术**: 纯HTML/CSS/JavaScript，无需额外依赖
- **数据存储**: 使用浏览器localStorage存储客户数据
- **安全特性**: 前后端分离，后台需要登录验证
- **UI设计**: 苹果风格，简洁大气
- **响应式**: 完美适配桌面、平板、手机

## 数据管理

- 客户咨询信息自动保存到浏览器本地存储
- 后台管理系统可以查看、删除客户记录
- 支持数据导出为CSV格式
- 数据统计功能，包括今日新增、咨询类型统计等

## 注意事项

1. 后台管理系统与前台网站完全分离，前台无法直接访问后台
2. 客户数据存储在浏览器本地，清除浏览器数据会丢失所有记录
3. 如需在生产环境使用，建议将数据存储迁移到服务器数据库
4. 管理员密码可以在 `admin-login.js` 和 `admin.js` 文件中修改
